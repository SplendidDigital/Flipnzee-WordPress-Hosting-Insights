# Flipnzee WordPress & Hosting Insights — v1.3.1

A WordPress plugin that brings together WordPress development news, web hosting discussions, security updates, and infrastructure insights in a clean, responsive interface.

## Features

- **Four RSS feed sources:** Reddit r/WordPress, Reddit r/webhosting, the WordPress Developer Blog, and the Cloudflare Blog.
- **Configurable article counts:** Choose how many articles to display from each source using a shortcode attribute.
- **Responsive design:** Displays feed sections vertically, with readable article titles, descriptions, publication dates, and source links.
- **Administrator-only cache clearing:** Allows authorized administrators to clear the plugin's display cache.
- **Feed caching:** Caches retrieved articles to reduce repeated requests.
- **Secure output handling:** Sanitizes and escapes feed content and validates article links.

## Installation

1. Download the plugin ZIP file from the Assets section below.
2. In your WordPress dashboard, navigate to **Plugins → Add New Plugin → Upload Plugin**.
3. Upload the ZIP file and activate the plugin.

## Shortcodes

Display up to three articles from each source:

`[flipnzee_insights]`

Display up to six articles from each source:

`[flipnzee_insights count="6"]`

The `count` attribute accepts values from 1 to 10.
